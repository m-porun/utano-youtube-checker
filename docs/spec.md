# 六甲おろしカウンティング 仕様書

## 概要

YouTubeの特定再生リストを全件走査し、VTuber「白珠ウタノ」が歌枠で「六甲おろし」を歌った動画・タイムスタンプを抽出してCSVに出力する。

---

## 変数定義

| 変数名 | 型 | 初期値 | 説明 |
|---|---|---|---|
| `SearchCount` | int | 0 | 調査した動画の累計件数 |
| `VideoTitle` | string | null | 動画タイトル |
| `VideoLink` | string | null | 動画URL |
| `SetList` | string | null | 抽出されたセットリストコメント全文 |
| `RokkoCount` | int | 0 | 動画内で六甲おろしが歌われた回数 |
| `RokkoNo` | int | 0 | 六甲おろしが歌われた順番（1始まり） |
| `RokkoTimeStamp` | string | null | 六甲おろしに対応するタイムスタンプ（例: `01:23:45`） |
| `TotalRokkoCount` | int | 0 | 全動画を通じた六甲おろしの歌唱総数 |

---

## 対象プレイリスト

- URL: `https://www.youtube.com/playlist?list=PLUi5gdZovvGlyVfVOyzmgOwZ8jd0bT2mS`
- チャンネル名: 歌枠/KARAOKE

---

## 処理フロー

### Step 1: 再生リストの全動画URLを取得する

- 再生リストにアクセスし、全動画のURLとタイトルを取得する
- これが以降のループ処理の入力となる

---

### Step 2: 動画を1件ずつ調査する（以下をすべての動画に対して繰り返す）

#### 2-1. 調査開始

- `SearchCount` に 1 を加算する

#### 2-2. アクセス可否の確認

- メンバー限定などの理由でアクセスできない動画はスキップする
- ただしその場合も `VideoTitle` に `「アクセス不可` を記録し、後述のCSV出力（Step 4）は実行する

#### 2-3. 基本情報の取得

- `VideoTitle`: 動画タイトルを取得する
- `VideoLink`: 動画URLを取得する

#### 2-4. セットリストの抽出

人気順上位20件のコメントを取得し（返信コメントは不要）、以下の条件を**両方**満たすコメントを探す。

**条件A（`SetListHeading`）**: 以下のいずれかの文言を含む（大文字・小文字を区別しない）
- `セトリ` / `セットリスト` / `set list` / `setlist` / `タイムスタンプ` / `TS`

**条件B（`TimeStamp`）**: `hh:mm:ss` 形式のタイムスタンプを1つ以上含む

**抽出ルール**:
- 条件を満たすコメントが1件 → そのコメント全文を `SetList` にセットする
- 条件を満たすコメントが複数件 → タイムスタンプの数が最も多いものを `SetList` にセットする
- 条件を満たすコメントが0件 → `SetList` に `セットリストなし` をセットする

#### 2-5. 六甲おろしのカウント

- `SetList` が `セットリストなし` の場合、この Step はスキップする
- `SetList` の中のタイムスタンプで区切られた各曲を1曲単位として処理する
  - 「1曲分」= 先頭のタイムスタンプから、次のタイムスタンプ直前まで
- 各曲の中に `六甲おろし` という文言があった場合:
  1. `RokkoCount` に 1 を加算する
  2. `RokkoNo` に `RokkoCount` の現在値を代入する
  3. その曲の先頭タイムスタンプを `RokkoTimeStamp` に代入する
- `六甲おろし` が1件も見つからなかった場合、`RokkoNo` と `RokkoTimeStamp` は null のまま
- `RokkoCount` が 1 以上だった場合、`TotalRokkoCount` に `RokkoCount` を加算する

---

### Step 3: CSVへの出力

1件の動画調査が完了するたびに、以下のスキーマでCSVに追記する。

| カラム名 | 変数 |
|---|---|
| `検索件数` | `SearchCount` |
| `動画タイトル` | `VideoTitle` |
| `動画URL` | `VideoLink` |
| `セットリスト` | `SetList` |
| `六甲おろしが歌われた数` | `RokkoCount` |
| `六甲おろし番号` | `RokkoNo` |
| `タイムスタンプ` | `RokkoTimeStamp` |

**レコード数のルール**:
- `RokkoCount` が 0 の場合 → 1レコード出力（`RokkoNo` と `RokkoTimeStamp` は null）
- `RokkoCount` が 1 以上の場合 → `RokkoCount` の数だけレコードを出力する（各レコードに異なる `RokkoNo` / `RokkoTimeStamp` を入れる）

**出力例（六甲おろしが2回歌われた場合）**:
```
検索件数, 動画タイトル, 動画URL, セットリスト, 六甲おろしが歌われた数, 六甲おろし番号, タイムスタンプ
3, タイトルA, https://..., "セトリ\n00:01:00 ...", 2, 1, 00:45:00
3, タイトルA, https://..., "セトリ\n00:01:00 ...", 2, 2, 01:30:00
```

---

### Step 4: 変数リセット

CSV出力後、以下の変数を初期値に戻す（`SearchCount` はリセットしない）。

| 変数 | リセット後の値 |
|---|---|
| `VideoTitle` | null |
| `VideoLink` | null |
| `SetList` | null |
| `RokkoCount` | 0 |
| `RokkoNo` | 0 |
| `RokkoTimeStamp` | null |

---

### Step 5: ループ継続 / 完了

- 次の動画に進み、Step 2 から繰り返す
- 再生リストの全動画を処理し終えたら終了
- 完了時に以下を出力する:
  - `六甲おろしカウンティングが終了しました。`
  - 出力したCSVのファイルパス
  - これまでに六甲おろしを歌った総数: `TotalRokkoCount`

---

## 実装方針

- 最小限から段階的に拡張する
  1. 再生リストの全動画URL・タイトル取得
  2. コメント取得・セットリスト抽出
  3. 六甲おろしカウント
  4. CSV出力

- 定期実行による「新規動画の検知」機能は**現時点では対象外**（将来の拡張として保留）
- `docker-compose.yml` が必要な場合は、理由を説明してから作成の許可を求めること
